Who it’s for

  • Design offices and machine builders managing drawings per job
  • Manufacturing and QA teams controlling released procedures and checklists
  • Engineering contractors with multi-customer projects and many revisions
  • Teams replacing shared-folder chaos without adopting full PLM

Problems solved

Wrong revision to the shop

Keep a clear current revision and optional shop-floor Released-only views.

Inconsistent numbering

Automatic document numbers with configurable project patterns.

Hard vendor handoff

Print a transmittal ZIP of the exact revisions you issued.

Key capabilities

  • Projects with separate document registers and local vault folders
  • Automatic numbering (for example ProjectCode-Seq) with configurable pattern and width
  • Revision history (A, B, C…) with a clear current revision
  • Statuses: Draft, Review, Released, Obsolete — with dashboard counts and filters
  • Drag-and-drop and Import folder when migrating from a shared drive
  • Check-out / check-in, owner, reason-for-change, review due date and audit trail
  • Transmittal package (cover sheet + ZIP of issued revisions)
  • Shop floor mode and job packet / traveler for Released copies
  • Release can require a PDF viewing copy; print stamps for controlled / obsolete copies
  • Customer drawing numbers, effectivity and lightweight change notices
  • Search with wildcards; CSV export; one-click database backup
  • Duplicate-file warning by checksum; works fully offline on this PC

Three-step workflow

STEP 1

Create a project

Separate documents by customer or job and open the project vault folder.

STEP 2

Number, vault and revise

Create documents, import a drawing folder, track revisions and status.

STEP 3

Issue and export

Print a transmittal, use shop floor / job packet views, export CSV or back up the database.

Supported files

Vault common engineering formats: PDF, AutoCAD DWG/DXF, Solid Edge DFT/PAR/ASM/PSM, STEP/STP, DOCX, XLSX, PNG, JPG and more. Files open in your installed applications — no built-in CAD viewer and no AutoCAD or Solid Edge add-in.

Example output

A maintained engineering document register with revisions, a local vault of controlled files, CSV export, database backup and optional transmittal ZIP packages.

Data privacy

DocRev Manager is fully offline. Document files stay in a local vault on your PC; the app database and settings live under your Windows user profile. No cloud account is required. See our Privacy page. Questions: use the contact form.

Windows system requirements

Windows 10 version 1809 (build 17763) or later, or Windows 11. Keyboard and mouse. Install from Microsoft Store on a supported PC.

FAQ

Is DocRev Manager a full PLM system?

No. It is a Windows application for document numbering, revision tracking and a local vault. It is not a Teamcenter, Autodesk Vault or enterprise PLM replacement.

Does it need AutoCAD or Solid Edge add-ins?

No. DWG/DXF and Solid Edge files are vaulted and open in your installed apps. There is no CAD add-in.

What file types can I manage?

PDF, AutoCAD DWG/DXF, Solid Edge DFT/PAR/ASM/PSM, STEP/STP, DOCX, XLSX, PNG, JPG and other files you choose to vault.
