This page describes the public website and what we can verify about product data processing.

This website

The site is static HTML. The contact form posts to an endpoint you configure in assets/config.js (Formspree or similar). Until that endpoint is set, the contact form does not send mail from the browser.

Google Analytics measurement ID G-77043KQ3MP is included. An optional Meta Pixel ID may be set in configuration; none is hard-coded.

ERP Migration File Validator

Version 1 processes selected CSV, XLSX and SpreadsheetML XML files on the local Windows device. It does not upload files, create accounts or send telemetry. Logs may contain app version, event type, format, sanitized file name, counts, duration and sanitized exceptions. Logs do not contain record values or full paths. Users can open or clear logs from Settings.

BOM Compare Tool and DocRev Manager

BOM Compare Tool processes selected BOM files locally on the Windows device and does not upload them to our servers. DocRev Manager stores project documents in a local vault on the device and keeps its database under the Windows user profile; it does not require a cloud account. For DocRev Manager, see the Microsoft Store listing. For B2B products, use the contact form. For Lean Consult, see the App Store listing.
