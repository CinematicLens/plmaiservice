Supported input formats

CSV, XLSX and SpreadsheetML XML. Binary .xls and password-protected workbooks are not supported. XLSX macros, external links and embedded objects are rejected. Formulas are not executed.

Example output

A virtualized issue grid (severity, sheet, row, field, rule, message, original and suggested values) plus an XLSX report with executive summary, issues, reconciliation, corrections and profile.

Before versus after

Before

Migration files go straight into an ERP upload. Invalid dates, duplicates and missing keys appear as load errors.

After

The same Excel or CSV file is checked on Windows first. Invalid rows are listed, and an audit report can be exported before import.

Windows system requirements
