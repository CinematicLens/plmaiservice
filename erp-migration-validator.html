Problems solved

Invalid import rows

Catch missing required fields and wrong data types before upload.

Duplicate keys

Uniqueness checks report duplicate values in the file you opened.

No audit trail after a failed load

Export an XLSX report of issues instead of discovering them only inside the ERP.

Key capabilities

  • Excel and CSV validation, plus SpreadsheetML XML, with format detection
  • Required-field, data-type, duplicate and allowed-value checks
  • Date and number validation, including numeric range and control totals
  • Parent/child checks
  • Error summary and searchable issue grid
  • Error export as an XLSX audit report (free edition: sample of up to 100 records)
  • Pre-upload quality checks on this device
  • Deterministic corrections with an audit trail; original file is never overwritten
  • Built-in fictional Generic Material Catalog profile for practice—not a vendor template

Three-step workflow

STEP 1

Open the migration file

Drop or browse a CSV, XLSX or SpreadsheetML XML file. Processing stays on this device.

STEP 2

Run validation

Apply a reusable JSON profile. Review errors, warnings and suggested fixes.

STEP 3

Export a report

Write an XLSX audit report. Professional edition can also export a sibling corrected file. The source file is not overwritten.

Supported input formats

CSV, XLSX and SpreadsheetML XML. Binary .xls and password-protected workbooks are not supported. XLSX macros, external links and embedded objects are rejected. Formulas are not executed.

Example output

A virtualized issue grid (severity, sheet, row, field, rule, message, original and suggested values) plus an XLSX report with executive summary, issues, reconciliation, corrections and profile.

Before versus after

Before

Migration files go straight into an ERP upload. Invalid dates, duplicates and missing keys appear as load errors.

After

The same Excel or CSV file is checked on Windows first. Invalid rows are listed, and an audit report can be exported before import.

Licensing

Licensing is through Microsoft Store. Free edition validates up to 100 records per worksheet and can export a sample report of up to 100 records. The original file is never truncated. Professional edition: no application-level record limit, corrected-file export, complete reports and saved reusable profiles. Confirm live trial and licensing on the Store product page for your market. Refunds follow Microsoft Store policy.

Data privacy and local processing

Version 1 processes selected files on the local Windows device. It does not upload files, create accounts or send telemetry. Logs store event types, counts and sanitized file names—never record values or full paths. See also our Privacy page.

Windows system requirements

Windows 10 version 2004 (build 19041) or later, or Windows 11. Keyboard and mouse. Minimum usable resolution 1280 × 720. Display scaling 100%, 125%, 150% and 200%.

FAQ

Is this an SAP product?

No. ERP Migration File Validator is an independent product and is not affiliated with, endorsed by or sponsored by SAP, Microsoft or any other ERP vendor.

Does it upload my material-master file?

Version 1 does not upload data. Validation runs on this PC.

Can I export a corrected file in the free edition?

No. Corrected-file export is included in the Professional edition. The free edition can export a sample report.
