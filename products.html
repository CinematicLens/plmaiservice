DocRev Manager

Document and revision control for Windows — projects, automatic numbering, revisions, local vault, and CSV export.

Core features

  • Projects — Create and manage projects (e.g. PUMP-2026, PRESS-PLANT). Each project has its own vault folder and document list.
  • Automatic document numbering — Next number generated automatically (e.g. PUMP-2026-001). Pattern and sequence width configurable.
  • Revision control — Track revisions (Rev A, B, C…). Upload new files to add revisions; codes assigned automatically.
  • Local file vault — Files copied into a controlled local vault. Source files are not modified.
  • Search — By document number, title, discipline, or project. Supports wildcards (* and ?).
  • CSV export — Export the document register for reports, audits, or external tools.
  • Database backup — One-click backup of the SQLite database to a configurable folder.

Document lifecycle

  • Create documents with discipline (Mechanical, Electrical, Civil, Process, General) and status (Draft, Review, Released, Obsolete).
  • Per-document revision history with code, date/time, and current flag. Open any revision or vault folder from the app.

Supported file types

Drawings: PDF, DXF, STEP, STP. Office: DOCX, XLSX. Images: PNG, JPG. Other types can be vaulted.

Who it’s for

Mechanical/electrical design offices, machine builders, manufacturing/QA teams, and engineering contractors managing drawings, CAD files, and procedures per project.
