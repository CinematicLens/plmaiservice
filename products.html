BOM Compare Tool

Problem: Detect BOM differences quickly instead of comparing versions manually in Excel.

Features

  • Upload Source BOM and Target BOM, then Validate BOMs
  • Matched / Different / Source-only / Target-only summary filters
  • Side-by-side field values, including quantity differences
  • Column mapping review — what was compared vs ignored
  • Search, column picker, row detail and ignored-item review
  • Optional mapping presets / Mapping Manager when licensed
  • CSV or PDF export when entitled under your B2B licence
  • Inputs: CSV, Excel (.xlsx), JSON; PLMXML on Source; max 50 MB
  • Local Windows processing — files are not uploaded to our servers

For: Manufacturing and product-data teams, engineering offices, PLM/ERP export workflows

Problem: Validate migration files before ERP upload to reduce Excel and data-entry errors.

Features

DocRev Manager

Problem: Improve drawing and revision control so outdated documents do not reach the shop floor.

Features

  • Projects with separate document registers and local vault folders
  • Automatic numbering (e.g. ProjectCode-Seq) with configurable pattern
  • Revision history (A, B, C…) with a clear current revision
  • Statuses: Draft, Review, Released, Obsolete — dashboard counts and filters
  • Drag-and-drop and Import folder when migrating from a shared drive
  • Check-out / check-in, owner, reason-for-change, review due date, audit trail
  • Transmittal package (cover sheet + ZIP of issued revisions)
  • Shop floor mode and job packet / traveler for Released copies
  • Customer drawing numbers, effectivity and lightweight change notices
  • Search with wildcards; CSV export; one-click database backup
  • Duplicate-file warning by checksum; works fully offline
  • Vault PDF, DWG/DXF, Solid Edge, STEP/STP, Office, PNG, JPG and more

For: Design offices, machine builders, manufacturing and QA teams, engineering contractors

BAPI Guard (BAPILoad Guard)

Problem: Validate Excel/CSV offline, then load through customer-authorized SAP remote functions.

Features

  • Inspect Excel and CSV workbooks on the local PC
  • Map columns with a declarative JSON profile (no scripts)
  • Validate rows and build a Create / Change / Skip plan
  • Guided packs: manufacturing, commercial, plant-maintenance, documents
  • Sales Order and master-data oriented workflows
  • Submit only customer-allowlisted remote-enabled functions
  • Plan hashes bind approval; batches checkpoint
  • Read objects back: Verified, Discrepant, Ambiguous or Not Checked
  • Timeouts treated as unknown — no silent risky retries
  • Never writes SAP tables directly; sapnco.dll not included

For: SAP master-data analysts, manufacturing engineers, consultants · Independent — not affiliated with SAP SE
