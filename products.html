DocRev Manager (Document & Revision Control)

Document and revision control for Windows — projects, automatic numbering, revisions, local vault, and CSV export. Ideal for controlling drawings, procedures, and deliverables per project.

Windows • Microsoft Store

DocRev Manager

Projects, automatic numbering, revision control, local vault, search, CSV export, and backups.

Core features

  • Projects — Separate vault and register per project
  • Automatic numbering — Configurable pattern and sequence width
  • Revision control — Rev A, B, C… with history and current flag
  • Local vault — Controlled copy; source files unchanged
  • Search — By number/title/discipline/project (wildcards supported)
  • CSV export — Document register export for reporting and handover
  • Database backup — One-click SQLite backup

Lifecycle + file types

  • Status: Draft → Review → Released → Obsolete
  • Open current revision, any revision, or vault folder from the app
  • PDF, DXF, STEP/STP, DOCX, XLSX, PNG, JPG (and more)

Who it’s for

Design offices, machine builders, manufacturing/QA teams, and engineering contractors managing drawings and project deliverables.
