Frequently asked questions

Are these Windows applications?

Yes. BOM Compare Tool, DocRev Manager and ERP Migration File Validator are Windows software products.

Where do I buy them?

BOM Compare Tool and DocRev Manager are available on Microsoft Store. ERP Migration File Validator does not yet have a verified Store URL on this site.

Do you process my engineering files in the cloud?

ERP Migration File Validator version 1 processes selected files on the local Windows device and does not upload them. BOM Compare Tool and DocRev Manager are Windows desktop apps; see each product page and the Privacy policy for current data-handling details.

Do you offer Teamcenter consulting on this site?

No. This website sells three Windows products: BOM Compare Tool, DocRev Manager and ERP Migration File Validator.
